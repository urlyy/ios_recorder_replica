# iPhone 15 Pro 录音界面复刻

灵感：[主办方：燃烧了这么多 token，这单生意应该有戏吧？](https://www.bilibili.com/video/BV1nPY46cEaY/?vd_source=a107cbbbff93aef1882c0a285f77bcef)

本项目根据用户提供的 **iPhone 15 Pro、iOS 26.6.1「语音备忘录」录音界面截图**进行网页复刻。
以截图中的浅色界面为准，还原播放和暂停两种状态，不提供上传按钮。仅中间的播放／暂停按钮可操作，
其他控件只保留外观，灵动岛固定显示录屏样式。

## 音频使用

- 音频路径由 `app.js` 中的 `RECORDING.src` 指定，沿用当前本地音频配置。更换文件时修改此配置后刷新页面。
- 需要通过 HTTP 服务访问页面。直接以 `file://` 打开时，浏览器会限制通过 `fetch()` 读取和解码本地音频。
- 波形由 Web Audio 解码实际音频后提取振幅包络生成，不是静态图片、FFT 频谱或随机动画。
- 波形只在加载音频时生成一次。播放时波形在固定的蓝色播放线下滚动，所有波形柱始终保持黑色。
- 暂停只停止播放和滚动，不改变波形高度、颜色或已播放部分；继续播放从暂停位置开始。
- 总时长来自音频元数据。录音标题和日期在 `RECORDING` 中配置。
- 没有音频文件时显示空波形，并禁用播放。
- 「替换」、前后 15 秒、更多、完成、转写和设置按钮均不执行操作；波形也不支持点击或拖动跳转。
- 不采集麦克风，不实际录屏，不重新录制或覆盖音频文件。

## 样式核对

| 元素 | 实现说明 |
| --- | --- |
| 状态栏时间与电量 | 固定为 `16:17` 和 `78`；电池数字对照 `assets` 截图使用浅灰色 `#c7c7c7` |
| 静音、双卡信号、Wi-Fi、电池 | 使用矢量路径或 CSS 绘制，并对照用户截图校准 |
| 灵动岛 | 加宽的黑色胶囊，左侧红色录屏圆点持续呼吸；播放、暂停、播放结束时均保留 |
| 页面外围 | 冷浅灰色 `#e7ebef`，与手机顶部的 `#d0d0ce` 分开，保持可辨识的边界 |
| 更多与完成 | 三个圆点和纵向较高的对勾，对照截图调整颜色、圆形按钮和阴影 |
| 前后跳转 15 秒 | 镜像箭头，数字使用原生 SF Rounded 字形轮廓 |
| 播放／暂停 | 中间按钮在黑色实心三角形与黑色暂停双条之间切换，是唯一可操作控件 |
| 转写文本 | 圆角对话气泡，内部带两个实心引号 |
| 播放设置 | 三条横线，圆形调节点交错排列 |
| 底部按钮 | 始终显示「替换」；暂停时为红底白字，播放时为浅灰底灰字，点击无动作 |
| 播放线 | 始终为蓝色，不随播放／暂停改变 |
| 字体 | 数字使用 Apple 系统字体，标题使用苹方简体半粗体 |

已通过 macOS Chrome 的实际渲染字体检查，确认使用苹方简体和 SF NS，而不只是检查 CSS 字体声明。
非 Apple 平台可能使用回退字体。浏览器抗锯齿和 CSS 模拟的原生玻璃效果仍可能与 iOS 有差异，
本项目未通过逐像素差异比对认证。

录屏圆点使用独立的 CSS 动画：约 `1.8 秒`一轮，大小固定为 `12px`，
只在深红 `#b92f28` 和亮红 `#ff453a` 之间平滑变化明暗，中心位置固定，不与音频或波形联动。
这些是近似复刻参数，未经 iOS 26.6.1 实机视频逐帧测量，不是苹果公布的动画参数。
系统启用“减少动态效果”时保留静态红点。页面不实际录屏，也不增加录屏操作。

## 字体与跨平台差异

页面使用系统字体栈（`-apple-system`、`BlinkMacSystemFont`、`PingFang SC` 等），不打包任何 webfont。
字体渲染只取决于访问者的设备，与部署的服务器无关，Cloudflare 等静态托管不会改变这一点。

- **Apple 设备（macOS / iOS）**：命中苹方与 San Francisco，可完整还原截图效果。
- **Windows**：无苹方，中文回退到微软雅黑；**英文与数字回退到 Segoe UI / Arial 等**，字形、笔画粗细和字宽与 iOS 存在差异。
- **Android**：回退到思源黑体 / Roboto，同样与 iOS 不同。

苹方与 San Francisco 均有版权，不能随项目合法打包分发，因此本项目选择维持系统字体栈：
Apple 设备一致，其他平台使用本地回退字体。若要求全平台字体统一，需改用开源字体（如思源黑体）并做子集化自托管。

页面初始化时会用 `document.fonts.check` 探测苹方是否可用：仅在**缺少苹方**的设备上，
底部弹出一条会在数秒后自动消失的提示，说明已回退到系统字体；Apple 设备上不显示该提示。

## 验证范围

已检查 `320×700`、`375×812`、`393×852`、`430×932` 和 `1440×900` 五种视口尺寸。
验证播放、暂停后继续、播放结束后重播、波形数据和颜色稳定、非播放控件无动作、
录屏灵动岛常显、红点颜色变化及大小与中心稳定、动画独立于音频状态、减少动态效果、
页面内外背景区分、文件缺失处理和超过一小时的时长格式。测试音频仅在内存中生成，不作为页面素材。

回归脚本为 `scripts/verify-player.cjs`，需要 Node.js、Playwright 和 Chrome，并先启动本地 HTTP 服务。
默认测试地址为 `http://127.0.0.1:8080`，可通过 `BASE_URL` 修改；
Playwright 未安装在项目目录时，可用 `PLAYWRIGHT_MODULE` 指定已有模块路径。
