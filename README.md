# iPhone 15 Pro 录音界面复刻

灵感：[主办方：燃烧了这么多 token，这单生意应该有戏吧？](https://www.bilibili.com/video/BV1nPY46cEaY/?vd_source=a107cbbbff93aef1882c0a285f77bcef)

本项目根据用户提供的 **iPhone 15 Pro、iOS 26.6.1「语音备忘录」录音播放界面截图**做网页复刻，
是一个纯静态页面，无框架、无构建步骤、无外部网络依赖。以截图中的浅色界面为准，还原播放与暂停两种状态。

iOS 复刻界面里真正可交互的是三组控件：**播放／暂停**、**后退／快进 15 秒**、以及**左右拖动波形跳转**；
其余控件（更多、完成、转写、替换、设置）只保留外观、不响应点击。灵动岛固定显示录屏样式。
页面右下另有一个位于复刻界面之外、会自动隐藏的**辅助栏**，提供 GitHub 链接与本地音频上传，方便录屏而不干扰画面。

## 快速开始

页面通过 `fetch()` 读取并用 Web Audio 解码本地音频，浏览器会限制 `file://` 下的此类请求，因此需用 HTTP 服务访问：

```bash
python3 -m http.server 8080 --directory .
# 浏览器打开 http://127.0.0.1:8080
```

## 配置

页面顶部数据全部集中在 [app.js](app.js) 的两个常量里：

- `RECORDING` 对象：
  - `src`：音频路径，默认 `record/主要是想邀请您.m4a`，换文件后刷新页面即可。
  - `time`：状态栏左上角时间文本（24 小时制），默认 `12:34`，作为**起始时间**；播放时会随播放进度同步向前走。
  - `title`：录音标题。
  - `date`：录音日期文本。
  - `duration`：显示的总时长文本；**留空**则改为从解码后的音频元数据自动计算。
- `GITHUB_URL`：辅助栏「GitHub 仓库」按钮的链接，替换为你自己的仓库即可。

以上 `title`、`date`、`duration` 都只是**展示文本**，不影响真实播放时长与快进／后退的边界；
`time` 仅决定状态栏时钟的起点，时钟会按播放位置递增（暂停即停），但同样不影响播放逻辑。

## 音频与波形

- 波形由 Web Audio 解码实际音频后提取振幅包络生成，不是静态图片、FFT 频谱或随机动画。
- 波形只在加载音频时生成一次。播放时波形在固定居中的蓝色播放线下横向滚动，所有波形柱始终保持黑色。
- 暂停只停止播放和滚动，不改变波形的高度、颜色或已播放部分；继续播放从暂停位置开始。
- 后退／快进 15 秒会在 0 秒到音频真实时长之间做边界收敛，且不改变当前的播放／暂停状态。
- 拖动波形跳转：播放线始终居中，向右拖显示更早的音频（时间减小），向左拖前进（时间增大），拖动时暂停、松手后按原状态恢复。
- 没有音频文件时显示空波形并禁用播放；读取失败时状态区给出中文提示。
- 页面不采集麦克风、不实际录屏，也不重新录制或覆盖任何音频文件。

## 移动端与辅助栏

- 支持移动端：使用 `width=device-width`、`viewport-fit=cover`、`100svh` 高度和 `env(safe-area-inset-*)` 安全区适配，
  并有 `max-width:374px`（窄屏）与 `max-height:760px`（矮屏）两组响应式断点，`max-width:430px` 时辅助栏改为横向铺满。
- 辅助栏包含三个按钮：**GitHub 仓库**链接、**上传本地音频**、以及**隐藏**。
- 辅助栏位于 iOS 复刻界面（`.screen`）之外，加载后短暂显示并在约 **1.5 秒**后自动淡出；
  之后**只有鼠标／手指移动**会再次唤出，单纯的点击、点按或按键不会唤出它——这样录屏时它不会持续出现在画面里。
- 点击**隐藏**按钮会在本次会话内彻底关闭辅助栏（连鼠标移动也不再唤出），方便录屏时保持画面干净；此设置不会持久化，**刷新页面即恢复显示**。
- 上传的音频**只在浏览器内处理**：通过内存中的 object URL 读取并解码生成波形，不上传到任何服务器，刷新页面即恢复默认录音。
  上传**只替换音频与波形**，标题、日期等文本保持不变。

## 样式核对

| 元素 | 实现说明 |
| --- | --- |
| 状态栏时间与电量 | 时间由 `RECORDING.time` 配置（默认 `12:34`）；电量固定 `78`，电池数字对照 `assets` 截图使用浅灰 `#c7c7c7` |
| 静音、双卡信号、Wi-Fi、电池 | 使用矢量路径或 CSS 绘制，对照用户截图校准 |
| 灵动岛 | 加宽的黑色胶囊，左侧红色录屏圆点持续呼吸；播放、暂停、播放结束时均保留 |
| 页面外围 | 冷浅灰 `#e7ebef`，与手机顶部的 `#d0d0ce` 分开，保持可辨识的边界 |
| 更多与完成 | 三个圆点与纵向较高的对勾，对照截图调整颜色、圆形按钮和阴影，仅展示不响应 |
| 后退／快进 15 秒 | 镜像箭头，数字使用 SF Rounded 字形轮廓；可点击，跳转在 0～真实时长间收敛，不改变播放状态 |
| 播放／暂停 | 中间按钮在黑色实心三角形与黑色暂停双条之间切换 |
| 转写文本、播放设置 | 对话气泡与三线调节点，仅展示不响应 |
| 底部按钮 | 始终显示「替换」；暂停时红底白字，播放时浅灰底灰字，点击无动作 |
| 播放线 | 始终为蓝色，不随播放／暂停改变 |
| 录屏红点 | 固定 12px、居中不漂移，约 1.8 秒一轮在深红 `#b92f28` 与亮红 `#ff453a` 间呼吸，与音频／波形无关 |
| 字体 | 系统字体栈，数字用 Apple 系统字体，标题用苹方简体半粗体 |

## 字体与跨平台差异

页面使用系统字体栈（`-apple-system`、`BlinkMacSystemFont`、`PingFang SC` 等），不打包任何 webfont。
字体渲染只取决于**访问者的设备**，与部署的服务器无关，Cloudflare 等静态托管不会改变这一点。

- **Apple 设备（macOS / iOS）**：命中苹方与 San Francisco，可完整还原截图效果。
- **Windows**：无苹方，中文回退到微软雅黑，英文与数字回退到 Segoe UI / Arial 等，字形与字宽与 iOS 有差异。
- **Android**：回退到思源黑体 / Roboto，同样与 iOS 不同。

苹方与 San Francisco 均有版权，不能随项目合法打包分发，因此本项目维持系统字体栈：Apple 设备一致，其他平台用本地回退字体。
页面初始化时用 `document.fonts.check` 探测苹方是否可用，仅在**缺少苹方**的设备上弹出一条数秒后自动消失的提示；Apple 设备不显示。

录屏红点、灵动岛参数为近似复刻，未经 iOS 26.6.1 实机逐帧测量，不是苹果公布的动画参数。
系统启用「减少动态效果」时红点保持静态。浏览器抗锯齿与 CSS 模拟的玻璃质感仍可能与 iOS 有差异，本项目未做逐像素比对认证。
